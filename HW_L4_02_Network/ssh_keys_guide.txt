========================================
راهنمای SSH Key و Passwordless Authentication
========================================

بخش ۱: تولید SSH Key Pair (RSA 2048-bit)
----------------------------------------
دستور:
  ssh-keygen -t rsa -b 2048 -C "your-email@example.com"

فایل‌های تولید شده:
  ~/.ssh/id_rsa          : کلید خصوصی (هرگز به کسی ندهید!)
  ~/.ssh/id_rsa.pub      : کلید عمومی (برای به اشتراک گذاشتن با سرورها)

بخش ۲: نمایش کلید عمومی در فرمت مناسب
----------------------------------------
دستور:
  cat ~/.ssh/id_rsa.pub

خروجی یک خط است که با "ssh-rsa" شروع می‌شود.

بخش ۳: نحوه استفاده از کلید برای Passwordless Authentication
----------------------------------------
برای اتصال به سرور بدون رمز عبور، کلید عمومی خود را روی سرور مقصد
در فایل ~/.ssh/authorized_keys قرار دهید.

روش خودکار (با ssh-copy-id):
  ssh-copy-id user@server_ip

روش دستی:
  1. کلید عمومی را کپی کنید: cat ~/.ssh/id_rsa.pub
  2. روی سرور، آن را به ~/.ssh/authorized_keys اضافه کنید.
  3. مجوزها را تنظیم کنید:
       chmod 700 ~/.ssh
       chmod 600 ~/.ssh/authorized_keys

پس از این کار، بدون رمز عبور متصل می‌شوید:
  ssh user@server_ip

بخش ۴: فایل ~/.ssh/config برای راحتی اتصال
----------------------------------------
مثال فایل config:

Host myserver
    HostName 192.168.1.100
    User algh
    Port 22
    IdentityFile ~/.ssh/id_rsa
    ForwardAgent yes

سپس با دستور زیر متصل می‌شوید:
  ssh myserver
